One original one-line joke about office life: a calendar block set aside for
deep work is instantly undone by the very thing it was meant to keep out — a
manager booking a meeting titled "Quick sync about your deep work."

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (one line, under 200 characters,
UTF-8). Running it twice produces byte-identical output.
